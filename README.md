# TJ Gribbin — Portfolio

A focused personal portfolio for software engineering recruiting, built with Next.js, TypeScript, Tailwind CSS, and selected shadcn primitives.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

Portfolio copy and links live in `data/portfolio.ts`. The résumé PDF is served from `public/Timothy-Gribbin-Resume-2026.pdf`.

## Verification

```bash
npm run lint
npm run build
```

The site is ready for a standard Vercel Next.js deployment.
